Space Majesty

Run a station in the Solace system. Hire independent ship captains, post mining contracts and bounties, sell ore to the Factory and grow your station, while scavengers raid your miners.

How to run it

  1. Unzip the file anywhere.
  2. Run SpaceMajesty.exe. Keep the .pck file next to it.
  3. Windows may warn that the app is unrecognised, because it isn't signed. Click More info, then Run anyway.

Controls

  1. Left click selects; left drag turns the camera; scroll zooms; Option or Alt plus drag pans.
  2. Space pauses, 1/2/3 set the speed, Tab shows the system list, M switches map markers, Esc opens the menu.
